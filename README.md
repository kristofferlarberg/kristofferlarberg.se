# kristofferlarberg.se

A tool for making sense of my developer practice by listing all my developer skills.

## Structure

Skills are listed based on:
- Years of experience
- Confidence level
- Frequency of use

Three categories are used with their own sub categories (used as filter options):
- Process
- Technical

All skills are also tagged with `Extra interesting` and `Collaborated` where this is applicable. These are also used as filter options.

## Progressive enhancement

The site is statically generated and all interactive functionality (filter options) is rendered only when JavaScript is avalable in the users browser.
